# 打孔机与 G-code 参考

> 本文是"纸带 → 打孔 G-code"的完整规格:坐标系、纸带几何、Z 三层、路径规划、参数表、
> 上机校验流程、GRBL 配置建议与耗时模型。代码实现见 [`server/gcode.py`](../server/gcode.py);
> 总体架构见 [DEVELOPMENT.md](DEVELOPMENT.md)。

---

## 1. 坐标系(实机确认)

| 轴 | 含义 | 方向 | 原点 |
|---|---|---|---|
| **X** | 纸带横向 = 音调 | X+ = 向右 | **X0 = 纸带左边缘线**,且是**冲针圆心**位置(不是冲针边缘,无半径补偿) |
| **Y** | 纸带纵向 = 时间 | Y+ = 纸带向前(时间增加) | Y0 = 纸带起点(第一个时间步所在位置) |
| **Z** | 冲针 | 值越大越往下 | Z0 = 最高位 |

因此 G-code 里的 X 值 = **孔圆心到纸带左边缘的距离**,直接写目标值即可。

### Z 三层(重要)

| Z | 名称 | 用途 |
|---|---|---|
| **0** | 最高位 / 快速移动位 | 程序开始、结束、需要最大净空时 |
| **6** | **安全高度**(由工作位抬起 4mm) | **所有 X/Y 移动都在此高度进行** |
| **10** | 冲孔(工作位) | 冲孔时压下 |

⇒ **单次冲孔的实际 Z 行程 = 4 mm**(6 ↔ 10),而不是 10mm。这是提高节拍的关键。

## 2. 纸带几何与列坐标

- 纸带物理宽 **70 mm**;有效音频区 **57.5 mm**;左右空白各 **6.25 mm**(= (70−57.5)/2)。
- 30 个音列按 **edge 模式**分布:第 1 列(col0)与第 30 列(col29)的**孔圆心分别落在有效区两端**:

```
X(col) = 6.25 + col × (57.5 / 29)      # 列距 = 1.982759 mm
col0  = 6.250 mm      (左侧留白 6.25)
col29 = 63.750 mm     (右侧留白 6.25)
```

常用列坐标(便于核对):

| col | X (mm) | col | X (mm) | col | X (mm) |
|---|---|---|---|---|---|
| 0 | 6.250 | 10 | 26.078 | 20 | 45.905 |
| 2 | 10.216 | 12 | 30.043 | 24 | 53.836 |
| 5 | 16.164 | 15 | 36.000 | 26 | 57.802 |
| 8 | 22.112 | 18 | 41.940 | 29 | 63.750 |

> 若以后换成"按 30 等分格中心"的排布,把 `MachineParams.col_mode` 改为 `"center"`
> (列距变为 57.5/30,X(col)=6.25+(col+0.5)×列距)。

## 3. 时间 → Y 换算

机器以**恒定纸带速度 8 mm/s** 送带(120 BPM 场景),因此:

```
每步时间  step_seconds = 60 / (bpm × steps_per_beat)
每步进给  mm_per_step  = step_seconds × 8 mm/s
Y(row)    = row × mm_per_step
纸带长度  = 曲目时长(s) × 8 mm/s        ← 与"每拍格数"无关
```

示例(本工程卡农纸带:`bpm=160, steps_per_beat=16`):
`step_seconds = 0.0234375s` → `mm_per_step = 0.1875mm` → 14903 步 ≈ **2794 mm**。

> 提高/降低"每拍格数"只改变 Y 的**量化精度**,不改变纸带总长(总长只由时长×速度决定)。

## 4. 路径规划(实现规则)

1. **同排多孔必须停带**:同一 `row` 上多个 `col` = 同一条横线上的和弦,纸带停在对应 Y,
   按 X **依次**冲完该行所有孔,再继续送带。
2. **每行从最近端进入**:比较该行最小/最大列的 X 与当前 X 的远近,选择先冲哪一端,
   冲完不折返(减少空程;实测本曲 X 空移从 959s 降到 683s)。
3. **空行跳过**:只对有孔的行做 `G1 Y…` 定位,其余时间不送带。
4. **移动安全**:所有 X/Y 移动都发生在 Z=安全高度(6);冲孔动作走 6 → 10 → 6。
5. **结束不回 Y0**:冲完最后一个孔后 `G1 Y(last+50mm)` 继续前进 50mm,便于剪下纸带,然后 `G0 Z0`、`M30`。

生成的头注释里会带上:孔数、有孔行数、纸带长度、耗时预估与分解,便于上机前评估。

## 5. 参数表(`MachineParams`,server/gcode.py)

| 参数 | 默认 | 说明 |
|---|---|---|
| `paper_width_mm` | 70.0 | 纸带物理宽度 |
| `audio_width_mm` | 57.5 | 有效音频区宽度 |
| `ncol` | 30 | 音列数 |
| `col_mode` | `edge` | 列分布模式(`edge`/`center`) |
| `feed_mm_s` | 8.0 | 纸带名义速度(mm/s,用于 Y 换算) |
| `z_home` | 0.0 | 最高位/快速移动 |
| `z_safe` | 6.0 | 安全高度 |
| `z_work` | 10.0 | 冲孔位置 |
| `move_z` | 6.0 | X/Y 移动时保持的 Z(设 0 = 每次回最高位,更保险但更慢) |
| `z_feed` | 2000.0 | Z 下压/抬起速度(mm/min) |
| `dwell_s` | 0.1 | 冲孔停留(压住时间) |
| `xy_feed` | 3000.0 | X 空移速度(mm/min) |
| `y_feed_mm_min` | 480.0 | 送带定位速度(= 8mm/s × 60) |
| `y_tail_mm` | 50.0 | 结束后继续前进的距离(便于剪带) |

生成入口:
- GUI ⑤「生成打孔 G-code(GRBL)」→ 下载 `*_tape.gcode`(并弹出统计提示);
- CLI: `from server.gcode import MachineParams, tape_to_gcode`(或 `tools/make_preflight_gcode.py` 生成预校验文件)。

## 6. 上机前校验流程(建议顺序)

1. **干跑坐标**(抬高 Z 或断开冲针电气):
   - `out/canon_preflight_edges.gcode`:在 Y=0 同一横线上打 `col0`(X=6.25)与 `col29`(X=63.75)。
     量纸带左右留白是否各 6.25mm,确认**X 行程到得了两端、X+ 确实是向右**。
   - `out/canon_preflight_2holes.gcode`:第一个音符(row0/col2 → X≈10.216, Y=0)与
     最后一个音符(row14902/col26 → X≈57.802)。确认 **Y+ 确实是向前**、且 2794mm 处位置正确。
2. **确认 Y0 语义**:本纸带第一个音符恰在 Y=0;确认装夹时 Y0 就是纸带起点,而不是限位/未装带位置。
3. **确认纸带够长**:本曲冲孔段 2794mm + 尾部 50mm ≈ **2.84 m**。
4. 再跑整曲 `canon_full.gcode`;长文件建议先空跑一小段验证送带速度与定位。
5. 校验方法参考:用 `tools/make_preflight_gcode.py` 可按当前工程纸带重新生成预校验文件。

## 7. GRBL 侧建议配置

| 设置 | 说明 |
|---|---|
| `$100/$101/$102` | X/Y/Z 的 steps/mm(必须与机械一致;Z 的值决定脉冲频率上限) |
| `$110/$111/$112` | X/Y/Z **最大速率**(mm/min)。Z 需 ≥ `z_feed`(默认 2000 mm/min) |
| `$120/$121/$122` | X/Y/Z **加速度**(mm/s²)。冲孔节拍由它主导(见 §8) |
| `$130/$131/$132` | 各轴行程上限。**必须 ≥ X 63.75mm、Y 纸带总长(本曲 ~2.84m)** |
| 单位/模式 | 程序内已含 `G21`(mm)`G90`(绝对)`G94`(mm/min) |

**脉冲频率上限**:GRBL(Arduino)常见上限约 30kHz。若 Z 为 100 steps/mm、速度 2000mm/min(33mm/s)
⇒ 约 3.3kHz,没问题;但若把 Z 速度设成 2000mm/s 就会到 200kHz,**超出控制器能力**。

**长文件流控(当前未实现,见路线图)**:本曲 16000+ 行,上位机直连串口时必须流式发送
(GRBL 接收缓冲约 127 字节,按 `ok` 应答推进;`?` 查询状态;`!`/`~` 进给保持/恢复;`Ctrl-X` 软复位)。

## 8. 耗时模型与实测

单孔时间 ≈ `(2 × Z行程) / z_feed` + `dwell_s`;总时长 ≈ 送带 + X 空移 + Z 冲程 + 停留。

本工程卡农纸带(2618 孔 / 1093 个有孔行 / 2794mm)实测预估(参数按上表默认):

| 项目 | 时间 |
|---|---|
| 送带 | 356 s |
| X 空移 | 683 s |
| Z 冲程(4mm×2 @2000mm/min) | 628 s |
| 冲孔停留(0.1s) | 262 s |
| **合计** | **约 32 分钟** |

> ⚠️ 若把 Z 速度写得很高(如 F120000),**实际不会线性变快**:
> 4mm 行程内达到该速度需要极高加速度(`v²=2as`),步进机达不到,GRBL 会按 `$122` 自行限速。
> 想真正缩短节拍,应按实机 `$122` 与实测单孔 Z 用时重算。

**进一步优化的安全选项**:
- 提高 `xy_feed`(X 空移 3000 → 12000 mm/min):X 空移 683s → 约 171s,总量级约 22 分钟;
- 降低 `dwell_s`(0.1 → 0.03):再省约 180s;
- 两者都改前请确认机械不丢步、冲孔质量可接受。
